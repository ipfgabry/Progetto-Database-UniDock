# Progetto-Database-UniDock

NOTE SUL PROGETTO: UniDock 
Studente: Gabriele Romano | Matricola: 1000059841

Questa cartella contiene i file per il database e i test effettuati. Il file UniDock_Model.mwb mostra lo schema grafico delle tabelle. Lo script principale UniDock_Setup.sql crea l'intera struttura del database, inclusi indici, trigger e la vista per il calcolo dinamico. Ho incluso anche unidock_query.sql per eseguire un popolamento massivo con oltre 100 record e 15 scenari di test complessi. La Relazione.docx analizza i requisiti e le scelte progettuali, mentre il file Result_Grid.csv riporta i dati estratti dai test finali.

Per avviare il progetto, apri MySQL Workbench con il servizio MySQL attivo (tramite XAMPP o standalone). Carica ed esegui per primo lo script UniDock_Definitivo.sql che è un file che mette insieme i file Unidock.Setup.sql e UniDock.query.sql per rendere l'apertura del database immediata. Al termine dell'esecuzione, la tabella con il riepilogo contabile apparirà automaticamente nella Result Grid.

Nota: Per l'ottimizzazione del codice SQL e della documentazione è stato utilizzato il supporto di strumenti di intelligenza artificiale.
